# formats/ — конфигурация lossless-форматов

Каждый файл `*.json` описывает один аудиоформат для оптимизатора LLAO. Конверторы в проект
НЕ включены: конфиг содержит всё необходимое, чтобы исполняемый процесс сам нашёл, скачал
по URL и подготовил нужную утилиту.

## Как добавить новый формат

1. Создайте `formats/<id>.json` по схеме ниже (за образец возьмите `flac.json`).
2. Положите в поле `downloads` рабочие ссылки на консольные утилиты (только Windows-версии;
   для ffmpeg-кодеков можно сослаться на общую сборку BtbN).
3. Точно опишите `caps` (каналы/битность/частота) и `tag.capabilities`, иначе формат либо
   попадёт на ошибки кодера, либо молча потеряет теги — это недопустимо.
4. Укажите `variants` — все параметры сжатия, которые надо перебрать.
5. Запустите `llao.exe check-formats`, чтобы провалидировать схему.

## Схема конфига

| Поле | Тип | Обязательно | Описание |
|---|---|---|---|
| `id` | string | да | Ключ формата (имя файла без расширения). |
| `name` | string | да | Человекочитаемое имя. |
| `extension` | string | да | Расширение результата без точки. |
| `homepage` | string | нет | Ссылка на сайт. |
| `enabled` | bool | нет | По умолчанию `true`. |
| `engine.kind` | string | да | `binary` (внешняя утилита) или `ffmpeg` (встроенный кодек). |
| `engine.executable` | string | для `binary` | Имя бинарника кодера. |
| `engine.decoder_executable` | string | нет | Бинарник для декода в WAV (по умолчанию = `executable`). |
| `engine.codec` | string | для `ffmpeg` | Кодек ffmpeg (например `alac`, `tta`, `mp4als`). |
| `engine.container` | string | для `ffmpeg` | Контейнер (например `m4a`, `tta`). |
| `downloads[]` | array | да | Способы получения утилиты (по ОС). |
| `downloads[].os` | string | да | `windows` \| `any` (кодеки доступны только в Windows-версиях). |
| `downloads[].url` | string | да | Прямая ссылка на архив или инсталлятор. |
| `downloads[].kind` | string | да | `archive` \| `extract7z`. |
| `downloads[].file_glob` | string | для `archive` | Где в архиве бинарник (glob). |
| `downloads[].files` | array | для `extract7z` | Имена файлов, которые надо извлечь из установщика (например `["la.exe", "la-core.dll"]`). |
| `downloads[].checksum` | object | нет | `{"type": "sha256", "value": "..."}`. |
| `downloads[].notes` | string | нет | Пояснения. |
| `cli_check` | object | нет | `{"cmd": [...], "expect": [...]}` — сверка конфига с реальным CLI утилиты (см. ниже). |
| `encode.cmd` | array | да | Шаблон команды кодирования. Плейсхолдеры: `{input}`, `{output}`, `{params}`, `{codec}`. |
| `encode.variants` | array | да | Все комбинации параметров: `{"id", "args", "note"}`. Пусто = один прогон. |
| `decode.cmd` | array | да | Шаблон команды декода в WAV: `{input}`, `{output}`. |
| `verify.kind` | string | нет | `builtin` (быстрая проверка целостности) или `none`. |
| `verify.cmd` | array | нет | Команда проверки, плейсхолдер `{input}`. |
| `tag.system` | string | да | `vorbis` \| `apev2` \| `id3` \| `id3v1` \| `mp4`. |
| `tag.writer` | string | да | Ключ тег-райтера: `flac` \| `wavpack` \| `monkeysaudio` \| `optimfrog` \| `id3` \| `mp4` \| `tak`. |
| `tag.capabilities` | object | да | `text`, `pictures`, `lyrics`, `cue_sheet`, `replay_gain`, `chapters` (bool). |
| `caps.channels` | object | да | `{"min": N, "max": M}`. |
| `caps.bit_depth` | array | да | Список поддерживаемых битностей (int). |
| `caps.sample_rate` | object | нет | `{"min": N, "max": M}`. |
| `notes` | string | нет | Пояснения. |

Правила:
- Команды — массивы строк, **без шелла** (`subprocess` без `shell=True`).
- `{params}` раскрывается в **список аргументов** варианта (`variants[].args`); если список пуст,
  на месте плейсхолдера не появляется ни одного аргумента. `{codec}` — из `engine.codec`.
- Первый элемент `cmd` — имя утилиты; при запуске оно заменяется на реальный путь
  (из `bin/<id>/`, PATH или результата скачивания).
- Если формат не может встроить какой-то класс тегов — честно укажите `false` в
  `tag.capabilities`: невместившиеся теги уйдут в ZIP-sidecar, данные не потеряются.
- `caps` должны быть консервативными: лучше исключить формат для файла, чем получить
  «успешное» кодирование с изменённой битностью/числом каналов.

## CLI для проверки

- `llao.exe check-formats` — валидация схемы всех `formats/*.json`.
- `llao.exe tools [fmt_id ...] [--no-download]` — статус/скачивание утилит
  (кэш в `bin/<id>/`, путь к бинарнику сохраняется в маркере `.binary`).
- `llao.exe help <fmt_id> -- --help` — запустить утилиту с `--help` и показать вывод
  (аргументы после `--` пробрасываются утилите без изменений).

Скачивание: по URL из `downloads[]`, проверка SHA-256 (если указана), распаковка zip,
результат копируется в `bin/<id>/` (для `engine.kind: "ffmpeg"` — в общий `bin/ffmpeg/`,
чтобы не качать ffmpeg.exe отдельно для каждого формата).

Особенности `downloads[].kind`:

- `archive` — распаковка zip, поиск бинарника по `file_glob` (регистронезависимо,
  предпочтение `win64`/`x64`/`amd64`), соседние файлы (DLL) копируются рядом.
- `extract7z` — скачанный инсталлятор (например NSIS-самораспаковывающийся) извлекается
  полным 7-Zip (`bin/7z/7z.exe` → рядом с exe → PATH; standalone `7za.exe` NSIS не понимает),
  из результата рекурсивным поиском забираются файлы из `files[]` и копируются в
  `bin/<id>/`. **Утилита никогда не устанавливается в систему** (нет Program Files, нет
  реестра, плагины winamp/foobar не создаются). Скачанный инсталлятор кэшируется в
  `bin/<id>/` и при повторном запуске не перекачивается.

## cli_check — контроль устаревания конфига

При подготовке утилиты вызывается `cli_check.cmd` (по умолчанию `["--help"]`), и вывод
(в нижнем регистре) проверяется на наличие всех подстрок из `cli_check.expect`. При
расхождении выдаётся предупреждение «конфиг, возможно, устарел» (работа не блокируется).
Примеры: FLAC — `["flac - command-line flac encoder/decoder", "version 1.5.0"]`,
ffmpeg — `["ffmpeg version"]`.

Кроме точечной проверки подстрок, релизный CI сравнивает полный вывод `cli_check` с эталоном
`.github/cli-baselines/<id>.txt` (`python3 .github/scripts/check_cli_baselines.py --compare`) —
любое изменение справки кодека блокирует релиз до обновления конфига и эталона (см. AGENTS.md).
